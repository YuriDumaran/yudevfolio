# Yuri's portfolio

A static, frontend only portfolio built with React and Vite. There is no backend.

## Get started

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Personalize

- Update the introduction, about section, and project entries in `src/main.jsx`.
- Contact links use your LinkedIn, GitHub, and email details.
- Norovia is featured first, with its live link and your Technical Lead & Developer role.
- NK Studio Portfolio is featured second as an in-development project.
- Its project card uses a custom NK Studio wordmark while the site is in development.
- Musings opens as a separate view with an entry sidebar and Previous/Next navigation. Add entries in `src/data/musings.js` with a date, topic, title, excerpt, and content; newest entries go at the top.
- Update the Experience timeline in `src/data/experience.js`.
- Update the page title and description in `index.html`.
